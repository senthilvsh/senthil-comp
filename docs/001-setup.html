Development Setup

I have chosen a Linux-based system as both the development and runtime environment for this project. So either a native or WSL2 based Linux distro is needed for a seamless developer experience.

You could get it work on macOS initially using a typical Xcode Command Line Tools setup, but in the near future when the project starts using an X11 window for I/O, you may have to do additional setup.

Running natively on Windows is possible. You have to either use the correct MSYS2/MinGW setup to build the project (hard!) or maintain your own version of code that uses Win32 API (harder!). I think most people will be better off using WSL2.

This is my setup. If you are unfamiliar with the tech stack, you can simply follow this.

Language C (C11 Standard)
Compiler gcc 15.2.0
Build GNU Make 4.4.1
Environment WSL2 (Ubuntu) on Windows 10 Home 22H2
IDE VSCodium

Environment Quick Start

If you are on WSL2 (Ubuntu), run the following commands in your terminal to update your system, install the core C development toolchain, and configure the necessary X11 libraries: 

# 1. Update your local package index
sudo apt update

# 2. Install the standard C/C++ compiler toolchain (GCC & Make)
sudo apt install build-essential -y

# 3. Install the X11 development headers for upcoming graphical features
sudo apt install libx11-dev -y

# 4. Verify your environment is functional
gcc --version
make --version
