A hobby project where I build a complete, self-contained 32-bit computing platform from scratch.

Modern computers, in general, implement the stored-program concept, meaning that both programs and data share a unified memory space. The CPU fetches instructions from this memory to execute them. Based on the instruction, it may read data from memory, process it and write it back to memory.
