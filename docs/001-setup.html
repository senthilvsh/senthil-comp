Development Setup

Toolchain

Language C (Standard: C11)
Compiler GCC 15.2.0+
Build System GNU Make 4.4.1+
Target OS Linux (Native or WSL2)
Dependencies X11 Development Headers (libx11-dev)

The versions shown above are taken from my current setup. They are not a strict minimum requirement. Older versions will most likely work too.

Ubuntu/WSL2

On Ubuntu based systems, run the command below to update packages, install the compiler toolchain, and fetch required graphics headers:

# Install core toolchain and X11 development headers
sudo apt update && sudo apt install -y build-essential libx11-dev

# Verify toolchain versions
gcc --version && make --version
