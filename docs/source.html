Setup

You need a Linux system (native or WSL2) to build/run this project. Other *nix environments could work, with some tweaks.

1. Install Toolchain

$ sudo apt update && sudo apt install -y build-essential libx11-dev

...or follow equivalent steps for your environment

2. Clone Repo

$ git clone https://github.com/senthilvsh/senthil-comp.git

3. Build

$ make

4. Run

$ ./vm
