A 32-bit System Design

The initial system design will have the following characterestics. It will be modified/expanded later as required by programming needs.

Registers

  • 32-bits wide
  • General purpose registers - R0 & R1
  • Instruction Pointer
  • Flags Register

Memory

  • 32-bit address bus - can address 2^32 = 4,294,967,296 bytes (4 GB)
  • 32-bit data bus - can fetch 4 bytes at once

Instructions

  • Variable length encoding
  • 8-bit & 32-bit data/operations
  • Signed & Unsigned math

Others

  • Little Endian - lower bytes are stored first in memory
  • Memory-Mapped IO - for communicating with I/O devices
