svm32

Build a complete 32-bit computer from scratch!

svm32 (pronounced 'swim 32') is a highly explorative, fun-filled journey to build a complete 32-bit computer from scratch. We will design an Instruction Set Architecture, implement a Virtual Machine that can execute it, write programs for this platform, then continue to build upwards layer by layer, and see how far we can go.
