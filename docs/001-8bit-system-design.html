An 8-bit System Design

Let us kick off this project by designing a minimal 8-bit system. We will describe the hardware components, the runtime behaviour and instructions.

Hardware

  • Registers - There are two general purpose registers R0 & R1 and an Instruction Pointer IP. All these registers are 8 bits wide.
  • Memory - An 8-bit address bus provides 2^8 = 256 bytes of address space. An 8-bit data bus allows reading/writing 8 bits at a time.
  • Execution - On startup, the CPU starts execution from location 0x00 in memory - the Reset Vector.

Instruction Set Architecture

Instructions have two parts - opcode and arguments. The opcode uniquely identifies the instruction among other instructions and its own variants. The arguments provide additional information to the CPU for execution.

  • An instruction can have zero or more arguments.
  • The first byte contains the opcode of the instruction.
  • Subsequent bytes are optionally taken up by arguments.

You might notice that a lot of important things are missing here—addressing modes, I/O devices, interrupts, and so on. This is a deliberate choice. I want to start with a minimal design first, and expand it only based on actual programming needs. This way, we can learn why each feature is needed and what problem it solves.
