A complete 32-bit computing platform

svm32 (pronounced as "swim 32") is a highly experimental, fun-filled, hobby project—where I attempt to build a complete 32-bit computing platform from scratch!

I have always been fascinated by computer architecture, assembly programming, compilers, and operating system concepts. I plan to develop a 32-bit instruction set architecture, implement a virtual machine, an assembler, and a basic runtime. Then I will try to develop a simple high-level language and a compiler. After that, if I have the time, skill and any patience left, I will try to experiment with a rudimentary file system, a single-tasking OS kernel, and some basic system calls. Things like virtual memory and multi-tasking are quite far away, but worth a mention here.

Let's be honest. A project of this scale is going to be a messy, chaotic ride. I fully expect to run face-first into architectural dead-ends, wrestle with infuriating bugs, and make plenty of boneheaded design choices. There will be setbacks and things will break.

But getting past all of those challenges and making the system work is where the ultimate payoff and satisfaction come from. I plan to document every single step of this journey right here—the breakthroughs, the false starts, and the moments when everything crashes in a ball of virtual smoke.

Whether this project ultimately succeeds, fizzles out, or fails spectacularly, the sheer joy of learning on the bare metal makes every roadblock and dead-end entirely worth it.
